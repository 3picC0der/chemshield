# Evidence
One folder per test ID (CHE-AT-01…04, ICS-AT-01…03, ISE-AT-01…03, INT-AT-01…03). Each holds: the signed test sheet, the data CSV, the plot, and the video (or a link to it).

ISE and integrated rows: regenerate everything under `evidence/ISE/` and `evidence/INT/`
with `python -m redosing.run_all` from the repo root. See `evidence/ISE/README.md`.
